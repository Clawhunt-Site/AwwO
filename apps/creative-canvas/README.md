# SuperClaw Creative Canvas

独立的 AI 创意工作流画布 MVP，包含：

- AI 剧本导演台、四幕节拍与场景目标；
- 分镜文案拆解、镜头卡与画幅网格；
- 3D 导演台、场景预演、焦段、机位、走位与灯光控制；
- Seedance 四块直出提示词、逐镜音效与15秒生成建议；
- WebGL 等距柱状 VR360 预览、视场角和视角导出；
- 可拖动的人物骨架、姿势锁定和骨架图回填；
- 多轨时间线、片段移动/裁剪/分割、撤销/重做和本地自动保存；
- 节点拖拽、类型化端口、连线、撤销/重做和本地自动保存。

首个版本运行在本地安全模式，不会调用付费图片或视频生成接口。

```bash
npm install
npm run dev
npm run build
```
