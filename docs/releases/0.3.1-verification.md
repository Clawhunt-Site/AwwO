# AwwO v0.3.1 release verification

## Scope and authorization

This release combines the verified private-server acceptance fixes with readable Agent conversations, exact-identity history recovery, safe draft acceptance and structural editing locks through native settlement. It retains the existing single-operator SSH access boundary; it does not enable public multi-tenant access or subscription billing.

On 2026-09-07 the operator explicitly approved: “允许本轮豁免 Gemini 审查，继续提交发布”. This exception applies only to this release's pending server-acceptance and conversation UX changes. Gemini did not pass review: the existing CLI authentication failed and the available API credential returned `403 / CONSUMER_SUSPENDED`. The standing dual-review rule remains unchanged for future work.

The reviewed source was developed in the isolated `server-acceptance` detached worktree from `6e1dc158a79e2f18c7bdf82610a353883b883f31` (v0.3.0). Its 79 pending files matched the frozen UX inventory exactly before version and release-document updates. No `server/` vendor change, credentials, runtime state or database content is included. Only `main` and `online` remain named branches; the reviewed release is promoted through those existing refs without force-pushing.

## Deployment contract

The authorized target is the existing private Ubuntu acceptance server, using a new immutable release directory and its existing isolated state. Preserve the prior release, service configuration and a cold state backup before switching. Reuse existing credentials without publishing them. Do not rerun the first-install script against the existing database.

The published Git tag identifies the source. Successful Git promotion alone does not prove deployment. The release receipt must separately record the source commit/tree/archive checksum, active service directories, live health/listener checks, browser/native execution outcome and rollback assets. Deployment results are published in the Forgejo release notes after verification; this pre-release source document does not claim that the later switch has already happened.
