使用指南：

1. 登录：选择页面提供的登录方式；登录失效后重新登录。
2. 工作区：选择你已加入的工作区；尚未加入时联系管理员。
3. 检索：输入关键词，按分类或标签筛选；无结果时修改关键词或清除筛选。
4. 浏览与编辑：查看成员阅读已发布版本；编辑者及获授权管理员可创建草稿，填写标题、分类、负责人、来源引用和正文，保存并修正质检问题后发布。编辑已发布文档会创建新草稿，旧发布版继续可读。
5. 数据看板：查看当前授权范围内的发布文档数和分类分布；待治理数仅对获授权角色展示。以页面标示的统计范围和时间为准。
6. 成员与权限：管理员管理成员及角色；所有权转移由 Owner 操作，始终保留至少一名活跃 Owner。管理员不能移除或变更 Owner；查看成员不能编辑文档。

前端消费方：F 知识库 Web 工作台；按 key 映射页面、权限及状态，记录物料覆盖情况。

## 交付规范

交付格式：仅 assets/copy/specifications 三个 Markdown 字符串，各≤1200字。copy 每行以首个全角冒号分隔稳定 key 与文案，共40个不重复key。
使用规则：保持key稳定；{scope}/{asOf}为服务端提供的统计范围/时间字符串，展示前转义；缺值时隐藏该元信息行。暂无正式名称，临时使用类别名“团队知识库”；暂按简体中文、清晰克制语气编写，正式名称、语气、多语言由产品负责人确认。
状态映射：401→auth.expired；账号停用依据明确错误码映射auth.disabled；403→common.forbidden或member.noPermission；404→doc.unavailable，不透露资源是否存在；409→doc.conflict；422→doc.invalid并展示安全字段提示；503/网络失败→对应失败态。读失败可重新加载；写失败不得自动重放，冲突先保留修改。成功文案仅在对应操作成功响应后展示。
入口规则：创建工作区入口须由F核对U/B契约后决定；doc.first仅用于可管理文档集合为空且可创建的状态。
权限映射：doc.first/create/save/publish仅在服务端允许相应动作时展示；Viewer不显示草稿及治理指标。已加载的空集合数值显示0；加载失败不能显示为0。demo.banner仅用于模拟页面且持续可见。前端隐藏按钮不能替代服务端授权。
